Приложение JobBoard: что за что отвечает

1) package.json
- Node.js-проект: перечисляет зависимости (Express, pg, dotenv, cors, node-fetch, nodemon).
- Определяет команды:
  - npm run dev — запуск в режиме разработки (nodemon)
  - npm start — запуск (node)

2) server_clean.js (используемый backend-скрипт)
- Главный сервер на Node.js (Express).
- Делает следующее:
  - Поднимает HTTP-сервер и обслуживает статические файлы из папки public.
  - Реализует REST API:
    - GET /api/health — проверка “живости” сервера.
    - GET /api/jobs?q=... — чтение вакансий из PostgreSQL с поиском по title/company/location/description.
    - POST /api/jobs — создание вакансии в PostgreSQL (обязательные поля: title и company).
    - GET /api/jobs/:id — получить одну вакансию по id.
    - DELETE /api/jobs/:id — удаление вакансии из PostgreSQL (для “своих” вакансий).
  - Реализует внешний поиск (пример):
    - GET /api/external-jobs?q=... — подгружает вакансии из внешнего источника и возвращает их в том же формате для фронтенда.
  - ensureTables():
    - автоматически создаёт таблицу jobs и индексы в PostgreSQL, если их ещё нет.

3) server.js
- Аналогичный backend-скрипт (ранняя версия).
- Если проект запускается через npm start/npm run dev, обычно используется server_clean.js.
- В текущем проекте server.js может остаться “на всякий случай”, но фактически запуск задаёт package.json.

4) db.js
- Подключение к PostgreSQL через пакет pg.
- Использует DATABASE_URL из .env.
- Экспортирует функцию query(text, params) для выполнения SQL-запросов.

5) db.sql
- SQL-схема базы данных.
- Задаёт таблицу jobs и индексы.
- Сейчас таблица создаётся автоматически из server_clean.js (ensureTables), поэтому db.sql не обязателен для работы.
- Но полезен для “ручного” разворачивания схемы или для проверки структуры.

6) .env (локальные секреты и настройки)
- Содержит рабочие параметры окружения:
  - DATABASE_URL — строка подключения к PostgreSQL
  - PORT — порт для запуска backend (если не задан, берётся дефолт)
- В репозиторий обычно не попадает (скрывается .gitignore).

7) .env.example
- Шаблон .env без реальных секретов.
- По нему удобно создать свой .env на новом ПК.

8) nginx.conf.example
- Пример конфигурации Nginx для развёртывания:
  - раздаёт фронтенд статики (index.html, CSS, JS)
  - проксирует запросы /api/ на Node.js (localhost:3000 или другой порт)
- Нужен, если проект публикуется в интернет.

9) public/ (frontend)
9.1) public/index.html
- Главная HTML-страница сайта.
- Содержит:
  - форму поиска (включая кнопку “Искать в интернете”)
  - блок со списком вакансий
  - форму добавления новой вакансии
  - подключение скрипта public/app.js и стилей public/styles.css

9.2) public/styles.css
- Стили интерфейса: карточки вакансий, кнопки, формы, раскладка.
- На логику работы API/БД не влияет.

9.3) public/app.js (логика фронтенда)
- Скрипт в браузере, который взаимодействует с backend через fetch:
  - GET /api/jobs — загрузка вакансий из PostgreSQL для “моих вакансий”.
  - POST /api/jobs — отправка формы “Добавить вакансию”.
  - DELETE /api/jobs/:id — удаление вакансии, но только для вакансий из локальной БД.
  - GET /api/external-jobs — загрузка вакансий из интернета (кнопка “Искать в интернете”).
- Также форматирует отображение карточек (дата, метаданные).
- В описании внешних вакансий выполняется очистка от HTML-разметки и обрезка до короткого текста.

10) .gitignore
- Настраивает, что НЕ отправлять в репозиторий:
  - node_modules/
  - .env (пароли/секреты)

11) package-lock.json
- Зафиксированные версии зависимостей.
- Обычно полезен для воспроизводимости установки на другом ПК.

Как всё связано в рабочем процессе
- Браузер открывает public/index.html → загружается public/app.js.
- public/app.js делает HTTP-запросы к backend /api/...
- server_clean.js принимает запросы, обращается к PostgreSQL через db.js.
- Данные вакансий берутся из таблицы jobs.
- Nginx (если настроить) может раздавать фронтенд и проксировать /api/ на Node.js.

require('dotenv').config(); // Загружает переменные окружения из файла .env в process.env (например DATABASE_URL, PORT)
const express = require('express'); // Подключаем библиотеку Express — удобный фреймворк для создания веб-сервера и API
const cors = require('cors'); // Подключаем middleware CORS — разрешает запросы к API с других источников (доменов/портов)
const path = require('path'); // Подключаем модуль path — помогает безопасно собирать пути к файлам/папкам
const fetch = require('node-fetch'); // Подключаем fetch для Node.js — чтобы делать HTTP-запросы к внешним API
const db = require('./db'); // Подключаем наш модуль работы с PostgreSQL (обертка над pg, функция db.query)
const app = express(); // Создаем экземпляр приложения Express (наш сервер)
const port = process.env.PORT || 3000; // Берем порт из переменной окружения PORT, а если её нет — используем 3000
app.use(cors()); // Подключаем CORS для всех запросов (чтобы фронтенд мог обращаться к API без блокировок браузера)
app.use(express.json()); // Включаем парсинг JSON-тела запросов (req.body будет объектом)
async function ensureTables() { // Функция, которая проверяет/создает таблицы в БД (асинхронная, потому что есть запросы к БД)
  const createTableSql = ` // SQL-строка (шаблонная), которую отправим в PostgreSQL
    CREATE TABLE IF NOT EXISTS jobs ( // Создать таблицу jobs, если её еще нет
      id SERIAL PRIMARY KEY, // id — автоинкрементируемый целочисленный ключ (Primary Key)
      title VARCHAR(255) NOT NULL, // title — строка до 255 символов, обязательное поле
      company VARCHAR(255) NOT NULL, // company — строка до 255 символов, обязательное поле
      location VARCHAR(255), // location — строка до 255 символов, необязательное поле
      salary VARCHAR(255), // salary — строка до 255 символов, необязательное поле (мы храним зарплату текстом)
      description TEXT, // description — текст произвольной длины, необязательное поле
      created_at TIMESTAMP WITHOUT TIME ZONE DEFAULT NOW() // created_at — дата/время создания, по умолчанию NOW()
    );
    CREATE INDEX IF NOT EXISTS idx_jobs_title ON jobs (title); // Индекс для ускорения поиска/фильтрации по title
    CREATE INDEX IF NOT EXISTS idx_jobs_company ON jobs (company); // Индекс для ускорения поиска/фильтрации по company
    CREATE INDEX IF NOT EXISTS idx_jobs_location ON jobs (location); // Индекс для ускорения поиска/фильтрации по location
  `;
  try { // Пробуем выполнить SQL-запрос к базе
    await db.query(createTableSql); // Выполняем SQL (создание таблицы/индексов) через db.query
    console.log('DB check: jobs table is ready'); // Пишем в консоль, что таблица готова
  } catch (err) { // Если при выполнении SQL произошла ошибка
    console.error('DB init error:', err); // Выводим ошибку в консоль, чтобы понять, что не так с БД
  }
}
app.use(express.static(path.join(__dirname, 'public'))); // Раздаём статические файлы (HTML/CSS/JS) из папки public
app.get('/api/health', (req, res) => { // Роут “проверка здоровья” сервера: GET /api/health
  res.json({ status: 'ok' }); // Отправляем JSON-ответ {status:"ok"}
});
app.get('/api/jobs', async (req, res) => { // Роут получения списка вакансий: GET /api/jobs
  const { q } = req.query; // Достаем query-параметр q (например /api/jobs?q=python)
  try { // Пробуем сделать запрос к БД
    let queryText = 'SELECT * FROM jobs'; // Базовый SQL: выбрать все поля из таблицы jobs
    const queryParams = []; // Массив параметров для безопасного SQL (чтобы не было SQL-инъекций)
    if (q && q.trim() !== '') { // Если q существует и не пустой после trim
      queryText += // Дописываем WHERE-условие к SQL
        ' WHERE title ILIKE $1 OR company ILIKE $1 OR location ILIKE $1 OR description ILIKE $1'; // ILIKE — поиск без учета регистра (PostgreSQL)
      queryParams.push(`%${q}%`); // Добавляем параметр $1: строка с %...% для поиска “содержит”
    }
    queryText += ' ORDER BY created_at DESC'; // Сортируем по дате создания: новые вакансии сверху
    const { rows } = await db.query(queryText, queryParams); // Выполняем SQL и берем rows (массив результатов)
    res.json(rows); // Отправляем вакансии в JSON
  } catch (err) { // Если ошибка при запросе/обработке
    console.error(err); // Печатаем ошибку в консоль
    res.status(500).json({ error: 'Ошибка при получении вакансий' }); // Отправляем клиенту 500 и сообщение
  }
});
app.post('/api/jobs', async (req, res) => { // Роут создания вакансии: POST /api/jobs
  const { title, company, location, salary, description } = req.body; // Достаем поля из JSON-тела запроса
  if (!title || !company) { // Проверяем обязательные поля
    return res.status(400).json({ error: 'Поля title и company обязательны' }); // Если нет — 400 Bad Request
  }
  try { // Пробуем вставить вакансию в БД
    const insertQuery = ` // SQL вставки
      INSERT INTO jobs (title, company, location, salary, description) // В какие поля вставляем
      VALUES ($1, $2, $3, $4, $5) // Значения через параметры (безопасно)
      RETURNING * // Вернуть вставленную строку целиком
    `;
    const { rows } = await db.query(insertQuery, [ // Выполняем INSERT и передаем массив параметров
      title, // $1
      company, // $2
      location || '', // $3 (если undefined/null — подставим пустую строку)
      salary || '', // $4
      description || '', // $5
    ]);
    res.status(201).json(rows[0]); // 201 Created + отправляем созданную вакансию
  } catch (err) { // Если вставка не удалась
    console.error(err); // Логируем ошибку
    res.status(500).json({ error: 'Ошибка при создании вакансии' }); // Отдаем 500
  }
});
app.get('/api/jobs/:id', async (req, res) => { // Роут получения одной вакансии по id: GET /api/jobs/123
  const { id } = req.params; // Берем параметр id из URL
  try { // Пробуем запросить вакансию
    const { rows } = await db.query('SELECT * FROM jobs WHERE id = $1', [id]); // SQL: найти по id
    if (rows.length === 0) { // Если ничего не нашли
      return res.status(404).json({ error: 'Вакансия не найдена' }); // 404 Not Found
    }
    res.json(rows[0]); // Отдаем найденную вакансию
  } catch (err) { // Если ошибка (например, БД недоступна)
    console.error(err); // Логируем
    res.status(500).json({ error: 'Ошибка при получении вакансии' }); // 500
  }
});
app.delete('/api/jobs/:id', async (req, res) => { // Роут удаления вакансии по id: DELETE /api/jobs/123
  const { id } = req.params; // Берем id из URL
  try { // Пробуем удалить из БД
    const { rowCount } = await db.query('DELETE FROM jobs WHERE id = $1', [id]); // DELETE-запрос, rowCount = сколько строк удалено
    if (rowCount === 0) { // Если ничего не удалилось — значит id не найден
      return res.status(404).json({ error: 'Вакансия не найдена' }); // 404
    }
    res.status(204).send(); // 204 No Content — успешное удаление, но без тела ответа
  } catch (err) { // Если ошибка удаления
    console.error(err); // Логируем
    res.status(500).json({ error: 'Ошибка при удалении вакансии' }); // 500
  }
});
function stripHtml(html) { // Функция очистки HTML-тегов из строки
  if (!html) return ''; // Если вход пустой (null/undefined/''), возвращаем пустую строку
  return html.replace(/<[^>]+>/g, ' ').replace(/\s+/g, ' ').trim(); // Удаляем теги, схлопываем пробелы, убираем пробелы по краям
}
app.get('/api/external-jobs', async (req, res) => { // Роут внешних вакансий: GET /api/external-jobs
  const { q } = req.query; // Берем строку поиска q (если есть)
  try { // Пробуем загрузить вакансии извне
    const response = await fetch('https://remoteok.com/api'); // Запрос к открытому API RemoteOK
    if (!response.ok) { // Если ответ не 200..299
      throw new Error('Failed to fetch external jobs'); // Кидаем ошибку, чтобы попасть в catch
    }
    const data = await response.json(); // Превращаем ответ в JSON
    let jobs = Array.isArray(data) ? data.slice(1) : []; // RemoteOK возвращает массив, первый элемент — мета-инфо, поэтому slice(1)
    jobs = jobs.map((job) => { // Преобразуем каждую вакансию в наш единый формат
      const rawDescription = job.description || job.description_plain || job.tagline || ''; // Берем описание (где оно есть)
      const cleanDescription = stripHtml(rawDescription); // Убираем HTML
      const shortDescription = // Делаем описание короче, чтобы не было огромной карточки
        cleanDescription.length > 600 // Если больше 600 символов
          ? `${cleanDescription.slice(0, 600)}…` // Обрезаем и добавляем многоточие
          : cleanDescription; // Иначе оставляем как есть
      return { // Возвращаем объект вакансии в нашем формате
        id: job.id, // id из внешнего сервиса
        title: job.position || job.title || 'Без названия', // название должности
        company: job.company || 'Не указана', // компания
        location: job.location || (job.remote ? 'Remote' : ''), // локация или Remote
        salary: job.salary || '', // зарплата (если есть)
        description: shortDescription, // очищенное/укороченное описание
        created_at: job.date || job.created_at || null, // дата (если есть)
        source: 'external', // метка, что это внешняя вакансия
        url: job.url || job.apply_url || '', // ссылка на вакансию/отклик
      };
    });
    if (q && q.trim() !== '') { // Если пользователь ввел поиск
      const query = q.trim().toLowerCase(); // Приводим запрос к нижнему регистру
      jobs = jobs.filter((job) => { // Фильтруем список
        const text = `${job.title} ${job.company} ${job.location} ${job.description}`.toLowerCase(); // Собираем текст для поиска
        return text.includes(query); // Оставляем только те, где есть подстрока
      });
    }
    res.json(jobs); // Отдаем список внешних вакансий в JSON
  } catch (err) { // Если что-то пошло не так
    console.error('External jobs error:', err); // Логируем ошибку
    res.status(500).json({ error: 'Ошибка при загрузке вакансий из интернета' }); // 500 с сообщением
  }
});
ensureTables().then(() => { // Сначала проверяем/создаем таблицу jobs, и только потом запускаем сервер
  app.listen(port, () => { // Запускаем сервер на нужном порту
    console.log(`Server running on http://localhost:${port}`); // Пишем в консоль адрес сервера
  });
});
